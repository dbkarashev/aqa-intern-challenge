Тестовое задание для AQA стажёра в компании учи

Подготовка к работе
-------------------

Для начала работы убедитесь, что у вас установлены [node.js + npm](https://nodejs.org/en/download)

Установите зависимости проекта, выполнив команду:
```shell
npm ci
```

Установите браузер для Playwright:
```shell
npx playwright install chromium
```

Запуск тестов
-------------

Запустите тесты с помощью команды:
```shell
npx playwright test
```

Что исправлено
--------------

- `getPopularArticles()` возвращал `locator.all()`. Этот метод не ждёт появления элементов, а статьи подгружаются уже после открытия виджета, поэтому `articles[0]` был `undefined`. Теперь метод возвращает локатор, и тест кликает по `first()`.
- Селектор кнопки «Написать нам» `[class^=btn]` находил несколько элементов, и клик падал со strict mode violation. Заменён на `[data-test=button_feedback_form]`.
- Заголовок читался через `textContent()` сразу после клика, до смены экрана. Теперь проверка через `toHaveText`, которая ждёт нужный текст.
- На главной идёт A/B-тест, и виджет есть не во всех вариантах. Перед открытием страницы ставится кука `ab_mainpage_redesign=a`.
- Баннер cookies может появиться с задержкой, а в разметке есть его скрытая копия. Видимая кнопка закрывается через `page.addLocatorHandler`.
- `trace: 'on-first-retry'` не срабатывал, потому что ретраев не было. Добавлен `retries: 1`.
- В README не было установки браузера.
